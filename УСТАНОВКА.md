# Установка с нуля

Пошагово, для Windows. Для Linux и macOS отличается одна строка — она отмечена.

## 1. Что нужно поставить заранее

* **Python 3.11 или новее** — [python.org/downloads](https://www.python.org/downloads/).
  При установке обязательно отметь галочку **«Add Python to PATH»**, иначе команды ниже
  не найдутся.
* **Git** — [git-scm.com/download/win](https://git-scm.com/download/win). Всё по умолчанию.

Проверка, что оба на месте (открой **PowerShell**):

```powershell
python --version
git --version
```

Должны ответить номерами версий. Если `python` не найден — Python поставлен без галочки
PATH, переустанови с ней.

## 2. Скачать бот

```powershell
cd $HOME\Desktop
git clone -b claude/csfloat-steam-email-registration-3q7lau https://github.com/FluffyDog000/csfloatreg.git csfloatbot
cd csfloatbot
```

Ветку указывать обязательно: в ней вся работа, в `main` старый код.

## 3. Окружение и зависимости

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m camoufox fetch
```

> **Linux / macOS:** вместо `.venv\Scripts\Activate.ps1` → `source .venv/bin/activate`

Последняя команда скачивает ~150 МБ — это сборка Firefox с антидетектом, один раз
на компьютер. Слева в строке приглашения появится `(.venv)` — значит окружение включено.
Его нужно включать **каждый раз** в новом окне PowerShell, перед запуском бота.

## 4. Свои данные

В папке лежат примеры — `accounts.example.txt`, `mails.example.txt`, `proxies.example.txt`.
Рядом с ними нужно создать свои файлы:

| Файл | Что внутри | Пример строки |
|---|---|---|
| `accounts.txt` | аккаунты Steam, по одному на строку | `mylogin:mypassword` |
| `mails.txt` | почты (firstmail), по одной на строку | `box@firstmail.ltd:mailpass` |
| `proxies.txt` | прокси, по одному на строку | `socks5://user:pass@host:10706` |
| `mafiles\` | папка с maFile'ами Steam Desktop Authenticator | `любоеимя.maFile` |

Почты и прокси — это **пул**: их может быть больше, чем аккаунтов. Кому какой достался,
бот запомнит сам в `data/bindings.json`.

maFile'ы сопоставляются с аккаунтами по полю `account_name` **внутри файла**, а не по
имени файла — переименовывать их не нужно.

Всё это можно не создавать руками: в шапке интерфейса есть кнопки загрузки файлов,
они лягут куда надо сами.

Проверить, что файлы прочитались:

```powershell
python main.py --check
```

## 5. Запуск

```powershell
python main.py
```

Откроется адрес `http://127.0.0.1:8000`. Три страницы:

* **Запуск** — массовая регистрация на CSFloat через Steam. Можно запускать всех или
  только отмеченных галочками, менять статусы руками, менять прокси пачкой.
* **Профили** — ручной антидетект-браузер: открыть профиль аккаунта, посмотреть пароли и
  код Steam Guard, вписать трейд-ссылку, подтвердить обмены (как в SDA), включить
  автоподтверждение.
* **Рассылка** — раздача предметов с одного аккаунта на все остальные по их
  трейд-ссылкам, с подтверждением и приёмом.

Остановить — `Ctrl+C` в окне PowerShell.

## 6. Обновления

```powershell
cd $HOME\Desktop\csfloatbot
git pull
```

Важно: **бот при этом должен быть закрыт**. Python держит в памяти тот код, с которым
запустился, и обновление на лету ничего не меняет — нужно закрыть окно и запустить снова.

Какая версия работает сейчас, видно в шапке интерфейса и первой строкой лога.

## 7. Если что-то пошло не так

| Что видно | Что делать |
|---|---|
| `Активация .venv\Scripts\Activate.ps1 ... выполнение сценариев отключено` | `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` в том же окне и повторить |
| `python : Имя "python" не распознано` | Python без галочки PATH — переустановить. Либо пробовать `py` вместо `python` |
| `ImportError: cannot import name 'CLoader' from 'yaml'` | `pip install --ignore-installed pyyaml` |
| `браузер camoufox не установлен` | `python -m camoufox fetch` при включённом `(.venv)` |
| Адрес `127.0.0.1:8000` не открывается | бот не запущен или занят порт: `python main.py --port 8001` |
| Нужно разобраться с подтверждениями Steam | `python main.py --conf-probe ЛОГИН` — разбор по шагам, ничего не подтверждает |

Остальные подробности — в `README.md`: форматы файлов, настройки `config.yaml`, статусы,
диагностика.

## 8. Чего делать нельзя

**Не передавай никому свои `accounts.txt`, `mails.txt`, `proxies.txt`, папку `mafiles\`,
а также `data\`, `state\` и `profiles\`.** Там пароли, секреты аутентификаторов, прокси и
живые сессии браузера. В репозитории их нет и быть не должно — они перечислены в
`.gitignore` именно поэтому. У каждого свои.
